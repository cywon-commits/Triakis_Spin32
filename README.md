# Triakis 삼각격자 S=3/2 Heisenberg AF — 원통 DMRG 결과 보고서

> **상태: 중간 보고서 (2026-10-23, χ ≤ 512 기준).** χ=1024(Ly=3), Ly=6 χ=512, 유한 열린 원통 섹터 스캔, 임계비 스캔 나머지 점은 아직 계산 중이며, 끝나면 이 문서를 갱신한다. 아래 결론에서 "잠정"이라고 적은 항목이 그 대상이다.

두 의뢰서를 함께 다룬다.
- [`REQUEST.md`](REQUEST.md): 세로 페리자성 위에서 **가로(순 모멘트 축 주위) 3부격자 질서가 있는가** (원통 iDMRG).
- [`BRIEF_ferrimagnet.md`](BRIEF_ferrimagnet.md): 기저상태가 **사이트당 m = S/3 페리자성**인가, 그리고 페리자성이 무너지는 임계비 (J_AA/J_AB)_c.

표기: J_AA = J1(모서리–모서리), J_AB = J2(모서리–중심). A = 모서리(corner), B = 중심(center). 에너지 단위 J_AB = 1. 코드 부호 규약은 중심 ⟨Sz⟩ > 0, 모서리 ⟨Sz⟩ < 0 (브리프와 전역 부호만 반대).

## 3. 방법

- 도구: TeNPy 1.1.1, `SpinSite(S, conserve='Sz')`, 2-site iDMRG + density-matrix mixer.
- 원통: 둘레 = Ly·a1 (Ly=3, 6; 3부격자와 호환), 길이 = a2. MPS 순서는 고리마다 (x=0: 모서리, 위 중심, 아래 중심), (x=1: …) — 중심은 자기 삼각형과 같은/인접 고리에만 결합.
- 자화 섹터: U(1) 보존으로 단위세포 Sz를 고정. 고리당 m 반정수 → 1고리 셀, 정수 → 2고리 셀. **주의:** m=5.5, 6.5를 1고리 셀로 돌리면 iDMRG가 두 상태 사이를 진동하며 수렴하지 않아(한계 순환) 2고리 셀로 다시 계산했다.
- χ 스케줄: 128 → 256 → 512 (이전 χ 상태에서 이어서), m=4.5는 1024 진행 중. 각 χ에서 ΔE/sweep < 1e−9 또는 최대 60 sweep.
- 관측량: 부격자별 ⟨Sz⟩; 전송행렬 스펙트럼을 전하 섹터별로(ΔSz=0 → ξ∥, ΔSz=±1 → ξ⊥, ΔSz=±2), 단위는 **고리 간격**(축 방향 √3/2); 같은/다른 부격자 모서리 및 모서리–중심 C⊥(r) = ½⟨S⁺S⁻ + S⁻S⁺⟩ 과 연결 Czz(r) (고리 0의 모서리 기준, 최대 60고리); 고리 경계 얽힘 엔트로피; 결합 에너지 ⟨S_i·S_j⟩; A 부격자 연결 구조인자 S_A(q).
- 초기 상태: 고전 페리 곱상태(중심 ↑, 모서리를 라운드로빈으로 올려 섹터 맞춤). 견고성 확인용으로 무작위 곱상태(seed) 재실행.

- 토러스(18스핀)는 S_tot=11 (3모서리당 5.5). 이 클러스터는 모서리–모서리 결합 6개가 중복(J=2)되는 특수 형태라 원통과 직접 대응하지 않는다. S=1/2·1의 같은 토러스 값(3, 7)도 각각 3S, 3.5S로 S에 따라 커지는 경향이 있어, 유한 크기 효과의 크기를 유한 원통 Lx=4, 6의 기울기로 분리할 계획이다.

→ **Ly=3에서 (J_AA/J_AB)_c ∈ (1.2, 1.4)**, 즉 고전 경계 1보다 0.2–0.4 크다 — 브리프 예측 4(양자 요동이 페리자성을 확장, 0.1–0.5 범위)와 정합. 붕괴 쪽에서는 A–A 상관이 반강자성으로 뒤집히고 S_A(K) 증가(0.60 → 0.91), ξ⊥ 급증 → 모서리 삼각 AF(120°) 성향의 상으로 넘어가는 것으로 보인다. 주의: Δ는 두 변분 상한의 차라 엄밀 부등식은 아니며, 붕괴 쪽에서 e(3.5)이 더 낮은 것은 유한 χ 편향과 반대 방향이라 강한 신호, 페리 쪽 판정은 상대적으로 약한 신호다.

### 4.6 고원 폭 (브리프 예측 3)
섹터 에너지의 르장드르 변환: 고리당 m=4.5 고원은 h=0⁺(자발 모멘트)부터 h_c2 = [e_ring(5) − e_ring(4.5)]/0.5 까지.

| χ | 128 | 256 | 512 | 외삽 |
|---|---|---|---|---|
| h_c2 / J | 0.33 | 0.38 | 0.41 | ≈ 0.42 |

→ 고원 폭 > 0.3 J (정합). 고원 위 m=5.5, 6.5로 계속 상승, m=6.5에서 ξ∥ ≈ 1700 (고원 위 gapless 마그논 액체).

## 5. 한계와 남은 작업

- **χ:** 4코어·15 GB 머신이라 χ=2048, 브리프의 3000–5000은 불가. Ly=3은 χ=512(절단오차 4×10⁻⁴)까지, χ=1024는 진행 중(sweep당 ~45분). Ly=6은 χ=256까지(512 진행 중)이고 절단오차 외삽은 아직 의미가 없다 — Ly=6 에너지는 보고값이 아닌 보조 지표로만 쓴다.
- **m* 하한:** e(3.5) vs e(4.5)를 iDMRG만으로는 확정하지 못함(4.1). 유한 열린 원통 Lx=4(S(N_B−N_A)=9), Lx=6(=18)에서 E(S^z_tot) 스캔 진행 중.
- **토러스 S_tot=11** 과 원통 m*=4.5의 차이 — 위 유한 원통으로 해소 예정.
- **임계비:** Ly=3, χ≤256만. Ly=6 스캔과 0.02 간격 세분은 미실시.
- **(선택) 키랄성 상관, 3고리 단위세포 시험**: 3고리 셀(m=4.5, χ=128) 대기 중. 키랄성은 실수 MPS·U(1) 고정 섹터에서 자명하게 0이라 미측정.
- 의뢰서와 다른 점: 브리프의 유한 원통(Lx≥24, 양끝 3열 제외) 대신 주 계산은 **무한 원통 iDMRG**(경계 없음). 유한 원통은 S_tot 판정에만 사용.
