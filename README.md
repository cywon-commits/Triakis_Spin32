# Triakis 삼각격자 S=3/2 Heisenberg AF — 원통 DMRG 결과 보고서

> 2026-10-23 · 계산 환경: 4코어 / 15 GB 클라우드 컨테이너, TeNPy 1.1.1.
> 주 계산은 Ly=3 무한 원통 χ ≤ 1024, Ly=6 χ ≤ 512, 임계비 스캔 χ ≤ 256. 아래 각 결론의 "신뢰도" 칸에 χ·Ly 한계를 명시했다.

두 의뢰서를 함께 다룬다.
- [`REQUEST.md`](REQUEST.md) (의뢰서 1): 세로 페리자성 위에서 **가로(순 모멘트 축 주위) 3부격자 질서가 있는가**.
- [`BRIEF_ferrimagnet.md`](BRIEF_ferrimagnet.md) (의뢰서 2): 기저상태가 **사이트당 m = S/3 페리자성**인가, 고원 폭, 그리고 페리자성이 무너지는 임계비 (J_AA/J_AB)_c.

표기: J_AA = J1(모서리–모서리), J_AB = J2(모서리–중심), A = 모서리, B = 중심, 단위 J_AB = 1. m = 고리(둘레 한 바퀴)당 S^z; Ly=3에서 고리 = 모서리 3 + 중심 6 = 9스핀이므로 **m = 4.5 ⇔ 사이트당 0.5 = S/3**. 코드 부호 규약은 중심 ⟨Sz⟩ > 0, 모서리 < 0 (브리프와 전역 부호만 반대).

**한 단락 결론 (의뢰서 1의 3.3 판정 기준).**
- S=3/2, J1=J2 triakis 원통에서 세로 페리자성은 유지된다. 다만 순 모멘트는 고전값 4S가 아니라 collinear 값 3S(사이트당 S/3)로 양자화되어 있다.
- 가로 성분에는 3부격자 질서가 없다. 근거는 셋이다. C⊥(r)이 1 격자상수 정도의 길이로 지수 감쇠하고, 같은 부격자 상관의 부호가 umbrella와 반대이며, ξ⊥가 Ly=3→6에서 커지지 않는다.
- ξ⊥는 χ=1024까지 χ 두 배마다 약 16%씩 꾸준히 커져 엄밀한 의미의 포화를 보이지는 않았다. 그래도 같은 파이프라인이 질서를 잡아내는 J_AB=0 대조군(두 배마다 46%, 값 자체가 30배 이상)과는 질적으로 다르다. 판정표 기준으로는 **"가로 부문 양자 무질서"** 행에 해당한다.
- 고전 그림(|L_Δ| = 2S, 비공면, 평탄 zero 띠)에서 기대한 umbrella 가로 질서는 양자 요동으로 사라진다. 대신 의뢰서 2의 order-by-disorder 그림, 즉 A-강자성 collinear 페리자성이 S=3/2 등방점에서 성립한다. A–A는 반강자성 결합인데도 ⟨S_A·S_A⟩ = +0.73 > 0이다.
- 이 고원은 J_AA/J_AB = 1.1보다 큰 값까지(Ly=3; 상한 미확정) 이어진다. 고전 Heisenberg에서는 J_AA/J_AB > 2/3이면 공선 상태가 이미 기울어지므로, 양자 요동이 공선 페리자성 영역을 크게 넓힌 것이다. 이 결과들은 triakis에 특유한 것이 아니라 임의의 삼각분할에서 같은 값을 주는 선도 차수 경쟁에서 나온다(§4.7). 고원 너머에서는 고전 해 m_cl = 6S − 2S·J_AB/J_AA처럼 모먼트가 커지는 쪽으로 고원을 벗어난다. J_AA/J_AB ≳ 1.3의 상은 단위세포 크기에 민감해 확정하지 못했다.

## 3. 방법

- **알고리즘:** TeNPy, `SpinSite(S, conserve='Sz')`, 2-site iDMRG + density-matrix mixer.
- **원통:** 둘레 = Ly·a1 (Ly = 3, 6, 3부격자와 호환), 길이 방향 = a2. MPS 순서는 고리마다 x = 0, 1, …에 대해 (모서리, 위 중심, 아래 중심)이다.
- **자화 섹터:** U(1)로 단위세포 S^z를 고정한다. 단위세포 고리 수 n은 1, 2, 3, 4를 썼다. m = 4.75는 4고리, m = 4.833은 3고리 셀이다.
- **χ 스케줄:** χ = 128 → 256 → 512 → 1024, 이전 χ 상태에서 이어서 계산했다.
  - 실행마다 χ ≤ 512는 70 sweep, χ=1024는 30 sweep을 돌았다(로그의 `finished after N sweeps`).
  - 대부분 ΔE/sweep < 1e−9 기준에 도달하기 전에 **최대 sweep 수에서 끊겼다**(`Maximum number of sweeps reached`).
  - `data/summary.jsonl`의 `sweeps` 필드는 sweep 수가 아니라 체크포인트 기록 수(10 sweep마다 1회)다. `dE_last`는 마지막 두 체크포인트, 즉 10 sweep 간 에너지 차이다.
  - 특히 χ=1024(m=4.5)는 dE_last = 9.5e−7로, χ=256 같은 섹터의 3.4e−10보다 네 자릿수 크다. 에너지 자체는 절단오차 1.4e−4 수준에서 신뢰할 만하다.
  - 그러나 전송행렬 스펙트럼(ξ⊥)은 에너지보다 수렴이 느리다. 이 실행은 χ=512 상태(ξ⊥ = 0.98)에서 출발했고 ξ⊥는 χ와 함께 단조 증가해 왔다. 따라서 χ=1024의 ξ⊥ = 1.13은 최종값보다 **작을(과소평가) 가능성**이 크다. 같은 상태를 100 sweep으로 연장하는 계산은 작업 환경 재시작으로 두 번 중단되어 완료하지 못했다.
- **관측량:**
  - 부격자별 ⟨Sz⟩
  - 전하 섹터별 전송행렬 스펙트럼: ΔSz=0 → ξ∥, ΔSz=±1 → ξ⊥, ΔSz=±2. 길이 단위는 **고리 간격**(축 방향 √3/2)이다.
  - C⊥(r) = ½⟨S⁺S⁻ + S⁻S⁺⟩와 연결 Czz(r): 고리 0의 모서리를 기준으로 최대 60고리까지
  - 고리 경계 얽힘 엔트로피, 결합 에너지 ⟨S_i·S_j⟩, A 연결 구조인자 S_A(q)
- **함정 두 가지:**
  1. m = 5.5와 6.5를 1고리 셀로 돌리면 iDMRG가 두 상태 사이를 진동하며 수렴하지 않는다. 그래서 2고리 셀로 다시 계산했다.
  2. **J_AA/J_AB ≳ 1.1에서는 단위세포 크기에 따라 에너지가 크게 달라진다.**
     - 1고리 셀은 같은 m에서 2고리 셀보다 0.16–0.69/고리 높다. 처음에는 1고리 셀의 e(3.5) < e(4.5)를 보고 "J_AA = 1.4에서 붕괴"로 잘못 판정했고, 이를 철회한 뒤 스캔 전체를 2고리 셀로 다시 계산했다.
     - 8고리 셀은 J_AA = 1.1–1.4에서 2고리 셀보다 다시 0.05–0.09/고리 낮다. 4·6고리 셀은 J_AA = 1.4에서 오히려 높게 나와(국소 최소) 주기를 단정할 수 없다.
     - **J_AA = J_AB에서는 1·2·3·8고리 셀의 m=4.5가 −29.1487 / −29.1488 / −29.1489 / −29.1490으로 일치한다.** 따라서 주 결과는 셀 크기에 영향받지 않는다.

  - J_AA = 1.0에서는 m=4.5가 변하지 않고(−29.1490) m=5만 0.015 내려가, Δ₊가 0.163 → 0.149로 조금 줄어든다. 고원과 m* = 4.5는 유지된다.

  - J_AA = 1.2·1.4에서는 두 섹터가 함께 0.05–0.09 내려간다.
  - 2고리 셀에서 보인 긴 ξ⊥(J_AA = 1.2–1.8에서 2–14)는 8고리 셀에서 0.8–0.9로 줄었다. **작은 셀이 만든 인공물이었다.**

- **셀 수렴에 대한 정정:** 이전 판에서는 "임계 구간의 ξ⊥가 2고리 셀보다 짧으므로 셀이 주기를 강제하지 않는다"고 썼다. 그러나 그 ξ⊥ 자체가 2고리 셀에서 잰 값이었고, 8고리 셀이 J_AA = 1.1·1.2의 m=5를 0.05–0.08 더 내렸다. 이 논리는 성립하지 않는다.
  - J_c는 셀 크기에 대해 아직 수렴하지 않았다.
  - 아래쪽 가장자리: J_AA = 1.1, χ=128, 2고리에서 e_ring(4.0) = −28.4091 > e_ring(4.5) = −28.4570이다. 유한 χ 편향과 같은 방향이라 보조 증거다.

- **(J_AA/J_AB)_c: J_c > 1.1 확정, 상한은 미확정.**
  - J_AA = 1.0에서 Δ₊ = +0.149(8고리 χ=128)는 관측된 모든 보정보다 한 자릿수 크다. 셀 보정 2→8고리는 −0.014, χ 보정은 128→256에서 +0.025, 256→512에서 +0.016이다.
  - J_AA = 1.1에서 Δ₊(8고리)는 −0.045 → +0.021 → **+0.063**(χ = 128 → 256 → 512)이다(의뢰서 5의 작업 G, 30 sweep, dE ≤ 2×10⁻⁶).
    - χ=512 값은 마지막 셀 보정(2→8고리, −0.034)보다 크고, 의뢰서의 판정 기준(+0.045)을 넘는다. 따라서 **J_c > 1.1을 확정한다.**
    - 이전 판에서 "J_c > 1.1은 주장하지 않는다"고 한 것은 셀 보정만 고려하고 χ 보정을 빠뜨린 판단이었다.
  - **상한은 아직 서지 않았다.**
    - J_AA = 1.1의 Δ₊는 χ = 128 → 512에서 +0.11 올랐다.
    - 그런데 J_AA = 1.2의 근거는 8고리 χ=128의 −0.055와 2고리 χ=256의 −0.038뿐이다. 같은 크기의 χ 보정이면 χ=512에서 양수가 될 수 있다.
    - J_AA = 1.2, 8고리 χ=256을 계산 중이다.
  - 참고값: 2고리 셀에서 ≈1.10(χ=128), ≈1.16(χ=256)이고, J_AA = 1.15의 Δ₊는 −0.054 → +0.011 → +0.037(χ = 128 → 256 → 512)이다. 8고리 χ=128에서는 ≈1.08이다. 모두 위의 상한·하한 성격을 가진다.
- **고전 경계와 비교:** 비교 대상을 둘로 나눠야 한다.
  - **Ising(공선 한정) 경계는 1**이다. J_AA = J_AB에서 매니폴드가 평탄해지는 점이 여기다(§2.2).
  - **고전 Heisenberg 경계는 2/3**다. 삼각형당 에너지를 최소화하면 |L_T| = min(3S, 2S·J_AB/J_AA)이므로, 공선(|L| = 3S)은 J_AA/J_AB ≤ 2/3에서만 고전 기저상태다. 수치 최소화가 이것을 정확히 재현한다. triakis(triangular)와 tetrakis square 모두 J_AA = 2/3 / 0.7 / 0.8 / 1.0에서 |L| = 3.000 / 2.857 / 2.500 / 2.000이다(§4.7).
  - 양자 결과 J_c > 1.1은 고전 Heisenberg 경계 2/3의 1.65배 이상이다. 즉 양자 요동은 페리자성 영역을 "1보다 0.1–0.2"가 아니라 **65% 이상 넓힌다.** 이전 판의 "고전 경계 1보다 0.1–0.2 크다"는 Ising 경계와 비교한 것이어서 결과를 크게 저평가했다.
  - 이미 J_AA/J_AB = 0.8에서 고전 해는 기울어져(|L| = 2.5 < 3S) 사이트당 m > 1/3인데, DMRG는 m* = 4.5 = S/3을 고원 간격 Δ₊ = +0.66으로 유지한다.
- **고원을 벗어나는 방향:** 모먼트가 **감소가 아니라 증가**하는 쪽이다. 고전 Heisenberg 해는 삼각형당 E = (J_AA/4)(L² − 3S²) − J_AB·S·|L|를 최소화해 |L| = 2S·J_AB/J_AA이고, 고리당 m_cl = 6S − 2S·J_AB/J_AA다. J_AA/J_AB = 1.2에서 m_cl = 6.5이므로 DMRG의 5.5와 같은 방향이다. 양자 계에서는 J_AA ≈ J_AB 근방에서 m이 3S로 고정되어 고원을 이루고, 임계비를 넘으면 고전 쪽으로 풀린다.
- **임계비 너머의 상 (미해결):**
  - 이전 판의 서술(2고리 주기, 긴 ξ⊥ 2–14, 모서리 120° 성향)은 **철회한다.**
  - J_AA = 1.4, m=4.5, χ=128의 셀별 에너지는 2고리 −28.3874, 4고리 −28.3508, 6고리 −28.3422, **8고리 −28.4735**다. 8고리가 0.086 낮고 ξ⊥ = 0.94로 짧다. 4·6고리가 높게 나온 것은 국소 최소이거나 주기가 맞지 않기 때문으로 보인다.
  - 8고리 셀에서도 Δ₊(1.4) = +0.027 > 0이라, J_AA = 1.1–1.2(8고리 χ=128에서 Δ₊ < 0)와 달리 m=4.5가 다시 m=5보다 낮다. Δ₊(J)가 단조롭지 않다.
  - J_AA = 1.4의 m=4는 8고리 셀에서 −28.3288이었다. 그러나 2고리 셀 값 −28.3861보다 높아 변분 단조성을 위반하므로(최적화 실패, 아래 검사) 올바른 상한은 −28.3861이다. 이 값은 8고리 m=4.5(−28.4735)보다 **0.087 높다**. 따라서 J_AA = 1.4에서 e(4) > e(4.5) < e(5), 즉 m = 4.5가 다시 최저라는 결론은 유지된다.
    - 8고리 셀 기준으로 Δ₊는 1.0: +0.149 → 1.1: −0.045 → 1.2: −0.055 → 1.4: +0.027이다.
    - 고원이 닫히는 구간은 J_AA ≈ 1.1–1.2 근방의 좁은 창일 수 있다. 그 뒤 1.4에서 S/3 섹터가 (긴 주기로 변조된 형태로) 다시 최저가 되는 재진입 구조가 보인다.
  - J_AA ≳ 1.3의 상(모먼트, 주기, 가로 상관)은 χ = 128, 셀 ≤ 8고리로는 확정할 수 없다. 현재 데이터로는 최적화 실패와 진짜 물리를 구분할 수 없으므로 이 영역은 "미해결"로 둔다.
- **변분 단조성 검사** (`triakis/analyze.py`의 `cell_monotonicity_check`, 결과 `results/cell_monotonicity.json`): 같은 χ에서 셀을 정수배로 키우면 작은 셀의 해가 큰 셀에 그대로 들어가므로 고리당 에너지가 올라갈 수 없다. 올라가면 최적화 실패다. 허용오차 10⁻⁴/고리로 현재 데이터에서 네 건이 걸리고, 모두 J_c 너머 영역이다.

- S=3/2에서 실패한 것은 큰 국소 차원(4)과 좁은 고원(0.38 J) 때문으로 본다.
- S=1/2의 h = 0.8(h_c2 ≈ 0.82 바로 아래)에서 χ=64는 m을 1/6보다 0.0014 높게 줬다. χ=128에서는 정확히 1/6(0.166668)으로 돌아왔다. 따라서 χ=64의 상승은 고원 끝 신호가 아니라 평활화였다. h = 0.8은 고원 안이다.
- S=1은 χ=64로는 판정이 불충분하다. h = 0에서 m = 0.3325(1/3보다 0.001 낮음)이고, h_c2(0.66 J) 위인 h = 0.9에서 0.416으로 오른다. 그러나 고원 안인 h = 0.4에서도 0.341로 1/3보다 0.008 높다. S=1의 χ=64 절단오차(~10⁻³)가 S=1/2(~10⁻⁴)보다 커서 섹터 혼합이 남은 것으로 본다. S=1의 프로토콜 판정은 χ=128 결과로 내린다.
- **S=1, χ=128:** h = 0.4에서 m = 0.333334로 정확히 1/3(고원)이고, h = 0.9에서 0.413으로 오른다. 따라서 χ=64의 h = 0.4 이탈(0.341)은 χ 부족이었고, **S=1에서도 프로토콜은 판정 기준을 통과한다.**
  - h = 0에서 m이 1/3보다 0.0008 낮은 것은 장이 없을 때 S^z ≤ 1/3인 다중항 성분들이 축퇴하기 때문이다(U(1) 없는 상태가 살짝 기울 수 있음).
  - e₀는 h = 0과 0.4에서 10⁻⁵ 안에서 같다.
- S=1 h = 0.4와 χ=128 실행은 계산 중이다. χ=256은 작업 환경 재시작으로 중단돼 χ ≤ 128만 돌린다.
- S=3/2 재시도는 의뢰서 4의 지시대로 하지 않았다.

### 4.7 일반 삼각분할로의 확장 (해석·고전 계산, `verification/general_triangulation.py`)

위 결과를 낳는 선도 차수 경쟁은 triakis에 특유한 것이 아니다. 토러스 위 **임의의 삼각분할**(A = 꼭짓점)에 삼각형마다 중심 스핀 B를 얹은 장식 격자에서 모두 같은 값을 준다. 두 번째 삼각분할로 차수가 균일하지 않은 tetrakis square(Union Jack, 차수 4와 8)를 택해 전수 열거와 고전 최소화로 확인했다(출력: `verification/general_triangulation.txt`).

1. **오일러 공식이 1/3을 정한다.** 3F = 2E와 V − E + F = 0에서 F = 2V이므로 N_B = 2N_A이고, (N_B − N_A)/(N_A + N_B) = 1/3이다. 즉 Lieb 값이 정확히 사이트당 S/3이다.

   | 격자 | V | E | F | F = 2V, E = 3V, deg = #tri | 차수 |
   |---|---|---|---|---|---|
   | triangular L=3 / 4 | 9 / 16 | 27 / 48 | 18 / 32 | ✓ | 6 |
   | tetrakis L=3 / 4 | 18 / 32 | 54 / 96 | 36 / 64 | ✓ | 4, 8 |

2. **평탄 Ising 매니폴드.** σ = ±1, 중심 최적 배치로 전수 열거했다.
   - J_AA = J_AB에서 triangular L=3(512개)과 tetrakis L=3(262,144개) 모두 **서로 다른 에너지가 1개**, 사이트당 −1이다.
   - J_AB = 1.2 J_AA에서는 둘 다 축퇴 2(A-강자성과 시간반전)다.
3. **O(λ²) 퍼텐셜이 A-강자성을 고른다.** E⁽²⁾ = −S² Σ_{σiσj=−1} 1/[S(|n_i|+|n_j|) − 1]이다.
   - A-강자성 상태에서는 차수 z인 A 사이트의 A 이웃 z개(평행)와 B 이웃 z개(반평행)가 상쇄되어 n_A = 0이고, 중심은 |n_B| = 3이다. 차수 z가 사라진다.
   - 따라서 E⁽²⁾/사이트 = −2S²/(3S − 1)이다.
   - 전수 열거로 두 격자 모두에서 최소점이 축퇴 2의 A-강자성이고, 값이 −1.0000(S=1), −1.2857(S=3/2)임을 확인했다.
4. **고전 Heisenberg 경계는 2/3이다.** 삼각형당 E_T = (J_AA/4)(L_T² − 3S²) − J_AB·S·|L_T|를 최소화하면 |L_T| = min(3S, 2S·J_AB/J_AA)다. 무작위 시작 12회 수치 최소화(S=1) 결과는 다음과 같다.

   | J_AA/J_AB | 0.4 | 0.6 | 2/3 | 0.7 | 0.8 | 1.0 | 1.2 |
   |---|---|---|---|---|---|---|---|
   | \|L\| 예측 | 3.000 | 3.000 | 3.000 | 2.857 | 2.500 | 2.000 | 1.667 |
   | \|L\| triangular L=3 | 3.000 | 3.000 | 3.000 | 2.857 | 2.500 | 2.000 | 1.667 |
   | \|L\| tetrakis L=4 | 3.000 | 3.000 | 3.000 | 2.857 | 2.500 | 2.000 | 1.667 |
   | 삼각형당 E (두 격자 공통) | −2.400 | −2.100 | −2.000 | −1.954 | −1.850 | −1.750 | −1.733 |

   차수가 균일하지 않은 tetrakis에서도 umbrella(|L| = 2S)가 완벽히 실현된다(표준편차 < 6×10⁻⁴). J_AA = J_AB에서 공선 상태의 고전적 손해는 두 격자 모두 사이트당 J S²/6이다.
5. **스핀 크기 의존성 (거친 추정).** 양자 이득 2S²/(3S − 1)·Jλ²와 고전 손해 S²/6·J의 비는 12/(3S − 1)이다. S = 1/2, 1, 3/2, 2, 3, 4에서 24, 6, 3.4, 2.4, 1.5, 1.09이고, λ = 1에서 S_c = 13/3 ≈ 4.3에서 1이 된다.
   - λ² 식을 λ = 1로 외삽한 것이라 계수는 거칠다. 또 양자 이득은 Ising 상태 기준이고 고전 손해는 고전 상태끼리의 비교라, 엄밀한 비교가 아니다.
   - 그래도 이득은 S에 선형, 손해는 S²에 비례한다. 그래서 **S가 작을수록 공선 페리자성이 더 견고하다**는 정성적 예측이 나오고, S = 1/2, 1 섹터 스캔(의뢰서 3의 작업 A)이 이를 직접 시험한다.

**범위:** 위 1–5는 해석·고전 계산이다. 양자(DMRG) 결과(m* = S/3, 가로 무질서, J_c > 1)는 triakis에서만 얻었다. tetrakis에서의 DMRG 확인(작업 C)은 하지 않았다.

## 5. 한계

- **χ:** 4코어·15 GB 머신이라 의뢰서의 χ = 2048, 브리프의 3000–5000은 불가능했다. Ly=3은 χ=1024(절단오차 1.4×10⁻⁴)까지 갔다. Ly=6은 χ=512까지이고 절단오차가 1.3×10⁻³이라 에너지 외삽이 의미가 없다. 그래서 Ly=6은 정성적 비교(ξ⊥가 Ly와 함께 커지지 않음)에만 썼다.
- **ξ⊥ 미포화:** χ=1024에서도 χ^0.21로 증가한다. "단거리"라는 결론은 크기(≈1 격자상수), 부호, 대조군과의 비교, Ly 의존성을 근거로 한다.
- **유한계 S_tot:** 유한 클러스터 두 종류가 무한 원통 값을 양쪽에서 낀다. 사이트당 m은 18스핀 토러스 0.611, 무한 원통 0.500, Lx=4 유한 원통 0.400(S_tot = 12)이다(§4.1 표).
  - 토러스는 중복된 A–A 결합 때문에 위로, Lx=4는 N_B/N_A = 1.5인 경계 지배 클러스터라 아래로 치우친다.
  - Lx=6은 S_tot = 22(유력) 또는 23, 사이트당 0.46–0.48로 0.5를 향해 올라간다. Lx=8은 하지 않았다(의뢰서 3에서 불필요로 판단).
- **임계비:** Ly=3, 2고리 셀 χ ≤ 512(J_AA = 1.15), 8고리 셀 χ ≤ 512(J_AA = 1.1)뿐이다. J_c > 1.1은 확정됐지만 상한은 셀 크기와 χ 양쪽에 대해 수렴하지 않았다. J_AA ≳ 1.3의 상은 미해결이고, Ly=6 스캔은 미실시다.
- **작업 B(자기장 직접 스캔)는 S=1/2(χ ≤ 128)와 S=1(χ=128)에서 검증됐다(§4.6c). h는 점 몇 개뿐이라 m(h) 곡선은 그리지 않았다. 작업 C(tetrakis DMRG)는 하지 않았다.** C는 우선순위가 낮아 실행하지 않았다. tetrakis에 대한 주장은 해석·고전 계산(§4.7)뿐이다.
- **선택 항목:** 스칼라 키랄성은 실수 MPS·U(1) 고정 섹터에서 자명하게 0이라 측정하지 않았다. 3고리 셀 시험(병진 깨짐 없음)은 완료했다.
- **설계 차이:** 브리프의 유한 원통(Lx ≥ 24, 양끝 3열 제외) 대신 주 계산은 **무한 원통 iDMRG**로 했다(경계 없음). 장(h) 스윕은 섹터 에너지의 르장드르 변환으로 대신했다(브리프 3단계 방식).
